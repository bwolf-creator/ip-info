# 🔍 IP Information Tool

A simple Python tool to display IP addresses from `ip a` command in a clean, readable format.

## 🚀 Features

- Shows all network interfaces
- Displays IPv4 addresses
- Works on Linux and WSL (Windows Subsystem for Linux)
- Simple and lightweight

## 📦 Requirements

- Python 3.6+
- Linux or WSL (Windows Subsystem for Linux)

## 🛠️ Installation

```bash
git clone https://github.com/yourusername/ip-info.git
cd ip-info
python3 ip_info.py
